Which Algorithm is Best?
  • 1. XGBoost (Recommended) The most powerful and accurate model. It excels at handling complex, non-linear sensor data and provides the best performance for energy tracking, making it the industry standard.
  • 2. Random Forest A robust, ensemble-based model. It prevents the overfitting issues of single Decision Trees, making it highly reliable, though slightly less accurate than XGBoost on complex data.
  • 3. Decision Tree A simple, highly interpretable model. While it is very fast, it is prone to overfitting and struggles with complex, noisy telemetry data.

Dataset Overview

Information regarding the data used for machine learning predictions

Number of Datasets

1 Kaggle Dataset

25,632 Records

The models were trained on the "HVAC System Power Consumption and Sensor Data" dataset from Kaggle, mapping sensor readings to energy consumption patterns.

Data Required for Prediction

  • Timestamp

    Essential to derive the day, week, and month features. Without these, the model cannot make a prediction.

  • On/Off Status

    This categorical feature is used to generate one-hot encoded status_ columns (e.g., status_0.0, status_1.0).

  • Damper Position

    Similar to on_off, this categorical feature also contributes to the one-hot encoded status_ columns.

  • Target Output Variable

    These columns from the original hvac_data_cleaned.parquet dataset are transformed into the features that the model expects for making predictions of active_energy.
